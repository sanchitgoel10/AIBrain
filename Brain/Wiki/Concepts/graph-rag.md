# Graph RAG

## Definition

Graph RAG is retrieval augmented generation that uses relationships between knowledge nodes, not only similarity between text chunks.

## Key Points

- Standard RAG works well when an answer lives inside one or a few documents.
- Harder questions often depend on relationships between documents and ideas.
- A graph lets AI follow connections between sources more efficiently than retrieving large numbers of unrelated chunks.
- The LLM Wiki is a simple local version of graph-guided retrieval built from Markdown, Obsidian links, and maintained Wiki notes.
