# Knowledge Graph

## Definition

A knowledge graph represents ideas as connected nodes and relationships. The source describes nodes as things such as people, ideas, places, events, concepts, or components; edges as named relationships; and triples as subject relationship object units.

## Key Points

- A graph grows as notes link specific concepts together.
- Obsidian `[[wikilinks]]` create graph-visible edges between notes.
- A personal knowledge graph can compound over time by preserving and extending prior thinking.
- [[llm-wiki|LLM Wiki]] applies this graph structure to AI-readable shared memory.
