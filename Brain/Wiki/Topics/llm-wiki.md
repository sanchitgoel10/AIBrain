# LLM Wiki

## Overview

An LLM Wiki is a structured memory layer for humans and agentic AI. It separates captured source material from compiled knowledge so agents can query reusable notes before reading broad raw context.

## Core Layers

- Raw sources preserve original material.
- Wiki notes compile topics, concepts, entities, projects, and logs from those sources.
- Schema files define the rules that keep future agent behavior consistent.

## Why It Matters

The transcript frames the LLM Wiki as a separate brain that AI agents can build and maintain automatically. The goal is not only storage, but reusable knowledge that stays traceable to source material.
